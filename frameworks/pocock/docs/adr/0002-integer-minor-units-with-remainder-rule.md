# Money is stored as integer minor units; equal-split Remainders go to Participants by a deterministic rule

"Exact, no rounding errors" can be met either with rational Balances (e.g. 1000/3 cents) or with whole-minor-unit Shares that add up exactly to the Amount. We chose integer minor units. Nobody can pay a fraction of a cent, so rational Balances would only push the rounding problem into Settle-up. Instead, each Expense splits into whole-unit Shares, and its Remainder is handed out one unit at a time to the Participants in the order they joined the Group. We use join order rather than the order in the request, so the same Expense always gives the same Shares. As a result, every Expense's Shares add up exactly to its Amount, and every Group's Balances add up exactly to zero. Changing the Remainder rule later would change historical Balances, so it is treated as fixed.
